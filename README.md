# Network Engineer Portfolio — V2

A high-performance, responsive portfolio built with plain HTML5, CSS3, and modern JavaScript. Networking is the primary identity; all 4 flagship repositories are linked with live modals, downloadable topologies, and interactive engineering features.

---

## ⚡ High-Impact Features Built-In

1. **Smart Auto-Hide Navbar** — Unobtrusively slides up out of view on scroll down to provide 100% clean reading space; instantly slides back down when scrolling up.
2. **Interactive CLI / Network Terminal Modal** — Accessible via the floating `>_ CLI` button or keyboard shortcut (`` ` `` / `~`). Run simulated commands like `ping`, `traceroute`, `show ip route`, `skills`, `projects`, `whoami`, `contact`, and `clear`.
3. **Cyber Dark / Editorial Light Theme Switcher** — Floating theme switcher with automatic preference persistence in `localStorage`.
4. **Copy-to-Clipboard Email Action & Toast Notification** — 1-click email copy with animated feedback banner.
5. **Topology / PKT Config Download Trigger** — Direct download trigger for the Enterprise Hybrid Network Architecture topology.
6. **Direct GitHub Repository Links** — Embedded both on each project card (`REPO ↗`) and inside the comprehensive case-study modal dialog.
7. **Scroll Progress & Scroll-Spy Navigation** — Real-time progress bar and dynamic navbar section highlighting.
8. **Interactive Canvas Graph** — Physics-based node and edge simulation in the hero that reacts to pointer movement.
9. **Accessibility & Reduced Motion Controls** — Floating motion toggle button, full `prefers-reduced-motion` compliance, and high-visibility keyboard focus rings.
